# 40HX 破解 · 快速操作手册

> 适用显卡：**NVIDIA CMP 40HX**（TU106，Device ID `0x1f0b`，PCI `10de:1f0b`）
> 目标功能：**解锁 PCIe Gen2 x16 + Tensor Core + ReBAR**（运行时解锁，不刷 VBIOS）
> 项目地址：<https://github.com/Cyridd/cmpunlocker>
> 本手册用途：新装 / 重装系统后，用最短路径把上面三项能力全部拿到手
>
> **一句话结论：算力会自动解锁；Gen2 的驱动内重训练永远会失败（跑得太早），必须开机后补一次。所以不用去查"为什么失败"，直接装一个补一次训练的服务就完事。**
> 实测平台：PVE 8.4 / `6.8.12-43-pve` / D1581 / GPU `05:00.0` / 上游根口 `00:03.0`

## 步骤 1 · 确认驱动版本

驱动版本必须与补丁匹配，版本不符会直接装不上或装上了不生效。先查：

```bash
# 方法 1：查驱动版本
nvidia-smi --query-gpu=driver_version --format=csv,noheader

# 方法 2：查已安装的 NVIDIA 包
dpkg -l | grep -i nvidia
```

支持的驱动版本：

| 驱动版本 | 说明 |
|---|---|
| `580.173.02` | 支持，仅离线校验通过（老版本，功能覆盖较少） |
| `610.57.04` | 支持 |
| **`615.78.08`** | **推荐**，本次实录全部实测数据来自该版本 |

如果显示其他版本、或 `nvidia-smi` 不存在，**先安装匹配版本的 NVIDIA 驱动**，再回来做解锁。驱动装错版本是这部分最常见的返工原因。

同时确认设备本身在线：

```bash
lspci -Dnn -d 10de:1f0b
```

期望：`0000:05:00.0 ... [10de:1f0b]`。记下这个 BDF，后面都要用。

再确认没被直通占用（有 `hostpci` 就是给虚拟机了，宿主机侧方案不适用）：

```bash
lspci -k -s $(lspci -Dnn -d 10de:1f0b | awk 'NR==1{print $1}') | grep -i 'in use'
grep -l hostpci /etc/pve/qemu-server/*.conf 2>/dev/null || echo "no passthrough"
```

期望：`Kernel driver in use: nvidia`；`no passthrough`。

## 步骤 3 · 执行安装

如果此前装过，先卸载干净：

```bash
sudo ./install.sh --uninstall
```

再按驱动版本安装（三选一）：

```bash
# 615.78.08（推荐，带诊断日志）
sudo ./install.sh --driver-version=615.78.08 --pcie-diagnostic

# 610.57.04
sudo ./install.sh --driver-version=610.57.04

# 580.173.02
sudo ./install.sh --driver-version=580.173.02
```

说明：`--pcie-diagnostic` 只多打几行日志，不影响功能，**排查时非常有用，建议默认带上**。安装器会校验源码 SHA256、用户态版本、Secure Boot，不要跳过这些检查。

装完核对（三条必须全绿）：

```bash
modinfo nvidia | grep -E '^(filename|version|vermagic)'
# filename 必须指向 /lib/modules/$(uname -r)/updates/cmpunlocker/nvidia.ko
# version 必须与你选的驱动版本一致，vermagic 必须匹配当前内核

cat /var/lib/cmp40hx/install-$(uname -r).manifest | head -8
# pcie_mode 应为 diagnostic（或 normal）
```


## 步骤 5 · 开机取读数（判断用，3 分钟）

```bash
GPU=$(lspci -Dnn -d 10de:1f0b | awk 'NR==1{print $1}')
nvidia-smi >/dev/null; sleep 2
sudo dmesg -T | grep -E 'CMP40_GSP_READY|CMP40_PCIE_GEN2' | tail -8
setpci -s $GPU CAP_EXP+2c.L CAP_EXP+30.W CAP_EXP+12.W
```

**正常（99% 的情况）会看到：**

```text
CMP40_GSP_READY_V551: feature=0x000000f3 ss0=0x88888888 ss1=0x00000008
CMP40_PCIE_GEN2_V2: LNKCFG=0x80085800(bits[19:18]=2) PL_RATE=0x00240036(bits[18:17]=2) CYA0=0x068731b3(DIS_G2=0)
CMP40_PCIE_GEN2_V2: RETRAIN_FAIL status=1101
00000002      ← CAP2
0000          ← CTL2
1101          ← LNKSTA
```

**这就是预期状态，不要去修它。** 它不是故障，是驱动做早了。直接进步骤 6。

读到别的就按下表分流：

| 现象 | 含义 | 处理 |
|---|---|---|
| 一条 `CMP40_PCIE_GEN2` 都没有 | 设备从未被打开过 | 先跑 `nvidia-smi` 再抓；仍是 0 就查模块是否加载 |
| `GSP policy not ready`，或 bits 不等于 2 | 补丁没生效，或用了旧源码树 | 删掉 `open-gpu-kernel-modules-615.78.08/` 重装，不要复用旧目录 |
| 完全没有 `CMP40_` 日志 | 加载的不是打过补丁的模块 | 回步骤 3 做那三条核对 |
| `RETRAIN_PASS status=1102` | 已经成了 | 跳过步骤 6，直接验收 |

## 步骤 6 · 安装「延迟补训练」脚本与开机自启

**本步骤的脚本原文就在下面，不需要仓库里的任何额外文件。** 复制粘贴即可，装到 `/usr/local/sbin/`，因为 systemd 单元只认这个路径。

### 6.1 写入补训练脚本

```bash
sudo tee /usr/local/sbin/cmp40-gen2-retrain.sh >/dev/null <<'CMP40_SCRIPT_EOF'
#!/usr/bin/env bash
# CMP 40HX late PCIe Gen2 retrain.
#
# Why this exists: the in-driver retrain runs inside nv_open(), immediately after
# the GSP bootstrap, and polls for 2 s. On at least one Intel server platform
# (D1581 / IIO root port 00:03.0) the link refuses to renegotiate at that moment
# even though the endpoint already advertises CAP2=00000006 and LnkCtl2=0002 --
# the driver logs "RETRAIN_FAIL status=1101". The same retrain issued a few
# seconds/minutes later trains to Gen2 x16 on the first try.
#
# So: wait for the driver, latch the endpoint capability with one rebind if it is
# still missing, then retry the standard sequence (TLS=5GT/s on both ends, Retrain
# Link on the upstream port) with a backoff schedule, and log which attempt won.
#
# Volatile by nature: run it on every boot.
set -u

TAG=cmp40-gen2
log() { printf '%s [%s] %s\n' "$(date '+%F %T')" "$TAG" "$*"; }

DEV=${CMP40_GPU:-$(lspci -Dnn -d 10de:1f0b 2>/dev/null | awk 'NR==1{print $1}')}
[ -n "${DEV:-}" ] || { log "no CMP 40HX (10de:1f0b) found"; exit 1; }

UP=$(basename "$(readlink -f "/sys/bus/pci/devices/$DEV/.." 2>/dev/null)")
[[ ${UP:-} =~ ^[0-9a-f]{4}:[0-9a-f]{2}:[0-9a-f]{2}\.[0-7]$ ]] || UP=""

rd32() { setpci -s "$1" "CAP_EXP+$2.L" 2>/dev/null | awk 'NR==1{print $1}'; }
rd16() { setpci -s "$1" "CAP_EXP+$2.W" 2>/dev/null | awk 'NR==1{print $1}'; }
wr16() { setpci -s "$1" "CAP_EXP+$2.W=$3" >/dev/null 2>&1; }

spd() { printf '%d' $(( 16#$1 & 0x0f )); }
wdh() { printf '%d' $(( (16#$1 >> 4) & 0x3f )); }

state() {
    printf 'CAP2=%s CTL2=%s LNKSTA=%s' \
        "$(rd32 "$DEV" 2c)" "$(rd16 "$DEV" 30)" "$(rd16 "$DEV" 12)"
}

has_gen2() {
    local c; c=$(rd32 "$DEV" 2c)
    [ -n "${c:-}" ] && [ $(( 16#$c & 0x04 )) -ne 0 ]
}

rebind() {
    log "rebind $DEV to latch the endpoint Gen2 capability"
    echo "$DEV" > /sys/bus/pci/drivers/nvidia/unbind 2>/dev/null \
        || { log "unbind rejected"; return 1; }
    sleep 1
    echo "$DEV" > /sys/bus/pci/drivers/nvidia/bind 2>/dev/null \
        || { log "bind rejected"; return 1; }
    nvidia-smi >/dev/null 2>&1
    return 0
}

attempt() {
    local c st i
    c=$(rd16 "$DEV" 30)
    [ -n "${c:-}" ] && wr16 "$DEV" 30 "$(printf '%04x' $(( (16#$c & ~0xf) | 0x2 )))"
    if [ -n "$UP" ]; then
        c=$(rd16 "$UP" 30)
        [ -n "${c:-}" ] && wr16 "$UP" 30 "$(printf '%04x' $(( (16#$c & ~0xf) | 0x2 )))"
        c=$(rd16 "$UP" 10)
        [ -n "${c:-}" ] && wr16 "$UP" 10 "$(printf '%04x' $(( 16#$c | 0x20 )))"
    fi
    for i in $(seq 1 40); do
        st=$(rd16 "$DEV" 12)
        if [ -n "${st:-}" ] && [ "$(spd "$st")" -ge 2 ]; then return 0; fi
        sleep 0.25
    done
    return 1
}

# Wait for the driver to attach and the device node to work.
i=0
while [ $i -lt 90 ]; do
    [ -e "/sys/bus/pci/devices/$DEV/driver" ] && nvidia-smi >/dev/null 2>&1 && break
    sleep 2
    i=$((i + 1))
done
log "start: $(state)"

if ! has_gen2; then
    rebind || log "rebind failed; will still try the retrain"
fi
if ! has_gen2; then
    log "Gen2 capability still absent after rebind; nothing to retrain"
    exit 1
fi

# Cumulative backoff: 0 / 5 / 20 / 55 / 130 / 265 s after the driver settled.
# The journal tells you which attempt won, i.e. how long this board needs.
for delay in 0 5 15 35 75 135; do
    sleep "$delay"
    if attempt; then
        log "PASS at +${delay}s: $(state) speed=$(spd "$(rd16 "$DEV" 12)") width=x$(wdh "$(rd16 "$DEV" 12)")"
        exit 0
    fi
    log "attempt at +${delay}s still Gen1: $(state)"
done

log "FAILED: link stayed at 2.5GT/s"
exit 1
CMP40_SCRIPT_EOF

sudo chmod 0755 /usr/local/sbin/cmp40-gen2-retrain.sh
```

### 6.2 写入 systemd 单元

```bash
sudo tee /etc/systemd/system/cmp40-gen2-retrain.service >/dev/null <<'CMP40_UNIT_EOF'
[Unit]
Description=CMP 40HX late PCIe Gen2 retrain
Documentation=https://github.com/Cyridd/cmpunlocker
After=systemd-modules-load.service nvidia-persistenced.service
# 不要加 ConditionPathExists=/dev/nvidia0：该条件只在启动瞬间判一次，
# 那时驱动还没建出节点就会被跳过，且 oneshot 不会重试。
# 等待驱动的工作交给脚本自己的 180 秒轮询。

[Service]
Type=oneshot
ExecStart=/usr/local/sbin/cmp40-gen2-retrain.sh
RemainAfterExit=yes
TimeoutStartSec=600

[Install]
WantedBy=multi-user.target
CMP40_UNIT_EOF
```

### 6.3 启用并立刻验证一次

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now cmp40-gen2-retrain.service
journalctl -u cmp40-gen2-retrain -n 20 --no-pager
```

期望看到：

```text
... [cmp40-gen2] start: CAP2=00000006 CTL2=0002 LNKSTA=1101
... [cmp40-gen2] PASS at +0s: ... speed=2 width=x16
```

如果 `start:` 那行是 `CAP2=00000002`，说明脚本自己做了 rebind 才把能力 latch 出来，属正常行为（脚本内置）。

**如果 journal 里只有一行 `was skipped because of an unmet condition check (ConditionPathExists=/dev/nvidia0)`** —— 说明单元里还留着旧版的条件行。`ConditionPathExists` 只在启动那一刻判一次：那时 NVIDIA 驱动还没建出 `/dev/nvidia0`，条件不满足，服务被直接跳过，而 `Type=oneshot` 不会自己重试。等待驱动本来就是脚本自己的活（180 秒轮询），这个条件纯属多余。修法：

```bash
sudo sed -i '/ConditionPathExists/d' /etc/systemd/system/cmp40-gen2-retrain.service
sudo systemctl daemon-reload
sudo systemctl reset-failed cmp40-gen2-retrain.service 2>/dev/null
sudo systemctl enable --now cmp40-gen2-retrain.service
systemctl cat cmp40-gen2-retrain.service | grep -i condition || echo "condition 已移除"
```

`systemctl cat` 那行输出 `condition 已移除` 才算改对了。

脚本行为说明（知道它在干什么，出问题才好判断）：

| 阶段 | 动作 | 说明 |
|---|---|---|
| 等待 | 最多 180 s 等驱动挂上且 `nvidia-smi` 可用 | 避免开机太早动手 |
| 补能力 | `CAP2` 缺 `0x04` 位时做一次 `unbind → bind` | 让端点重新 materialize Gen2 能力向量 |
| 重训练 | 双端 `LnkCtl2.TLS=5GT/s` + 上游 `Retrain Link` + 5 s 轮询 | 标准 PCIe 手段，不用 Link Disable |
| 退避 | `0 / 5 / 15 / 35 / 75 / 135` 秒累积重试 | 命中即记 `PASS at +Ns` 并退出 0 |

## 步骤 7 · 冷启动验收（这一步才算完成）

```bash
sudo poweroff      # 断电 10 秒再上电
```

开机 2–3 分钟后：

```bash
systemctl status cmp40-gen2-retrain --no-pager
journalctl -u cmp40-gen2-retrain -b --no-pager
lspci -vvv -s $(lspci -Dnn -d 10de:1f0b | awk 'NR==1{print $1}') | grep -E 'LnkSta:|LnkCtl2:'
```

**通过标准：**

```text
[cmp40-gen2] PASS at +Ns: ... speed=2 width=x16
LnkSta:  Speed 5GT/s, Width x16
LnkCtl2: Target Link Speed: 5GT/s
```

`+Ns` 里那个 `N` 是这台机器需要的等待时间。记下来——如果它稳定在某个值，可以把脚本里的 `for delay in 0 5 15 35 75 135` 改成固定 `sleep N` 直接试一次，这样开机到 Gen2 更快。

## 步骤 8 · 失败分流表

| journal / 现象 | 原因 | 处理 |
|---|---|---|
| `Gen2 capability still absent after rebind` | rebind 都 latch 不出能力位 | 先确认步骤 5 里 `GSP policy not ready` 没出现；仍是 `02` 则考虑 VBIOS / 平台问题 |
| 每轮 `still Gen1`，但 `CAP2` 已是 `06` | 链路确实训不上去 | 进 BIOS 把该槽 PCIe Speed 设 Gen2/Auto、关 CSM、开 Above 4G，冷启动再试 |
| `PASS` 了但几分钟后又掉回 `1101` | 有东西在恢复限制 | 观察 `MISC1`（工作机 `e0b42d00`，异常时是 `e0b46500/e0b44500`） |
| 服务没跑起来 | 单元未生效 | `systemctl daemon-reload`；确认 `/dev/nvidia0` 存在 |
| `was skipped because of an unmet condition check (ConditionPathExists=/dev/nvidia0)` | 单元里残留旧的条件行，启动瞬间节点还没出现 → 服务被跳过且不重试 | 删掉该行：`sudo sed -i '/ConditionPathExists/d' …` 后 `daemon-reload`（详见步骤 6.3） |
| `sh: 0: Illegal option -o pipefail` | 用 dash 跑了 bash 脚本 | 用 `bash 脚本.sh` 或 `sudo bash ...` 执行 |

## 步骤 9 · 完全卸载（回到原厂状态）

顺序不能反：**先让原程序把自己卸掉，再清掉额外加的开机任务和脚本**。反过来的话，卸载过程中若提示重启，那个还 `enabled` 的服务会先跑一次 —— 没有 nvidia 驱动它必然报失败，日志里多一段噪音，容易误判成"卸载没干净"。

先看清楚装过什么、分别在哪：

| 装了什么 | 位置 | 卸载动作 |
|---|---|---|
| 打过补丁的 `nvidia.ko` | `/lib/modules/$(uname -r)/updates/cmpunlocker/` | 9.1（原程序） |
| 延迟补训练脚本 | `/usr/local/sbin/cmp40-gen2-retrain.sh` | 9.2 第 4 步 |
| systemd 单元 + 开机软链 | `/etc/systemd/system/cmp40-gen2-retrain.service`、`multi-user.target.wants/` | 9.2 第 1–3 步 |
| 仓库与内核源码树 | `/root/cmpunlocker`、`/root/open-gpu-kernel-modules-*` | 9.5（可选） |

### 9.1 第一步 · 用原程序卸载（撤掉补丁驱动）

```bash
cd /root/cmpunlocker          # 换成你实际的目录
sudo ./install.sh --uninstall
```

它会撤掉打过补丁的 `nvidia.ko`、恢复安装前的驱动状态。跑完可能提示需要重启 —— **先别急着重启，把 9.2 做完**。

验证（三条）：

```bash
nvidia-smi --query-gpu=driver_version --format=csv,noheader
modinfo nvidia | grep -E '^filename|^version'
ls /lib/modules/$(uname -r)/updates/ 2>/dev/null
```

判据：
- `driver_version` 回到原厂版本（如 `615.78.08` 仍是该版本，但模块来源变了）；
- `filename` 指向 `.../kernel/drivers/video/nvidia.ko` 或 `.../updates/dkms/nvidia.ko`，**不再是** `.../updates/cmpunlocker/nvidia.ko`；
- `updates/` 下不再有 `cmpunlocker/` 目录。

如果 `install.sh --uninstall` 报"找不到安装记录"（目录被改名、或装的是别的版本），直接进 9.2，然后手工确认模块：

```bash
find /lib/modules/$(uname -r) -name 'nvidia.ko*'
```

多出来的 `updates/cmpunlocker/nvidia.ko` 手工删掉，再 `sudo depmod -a`。

### 9.2 第二步 · 关掉并删除开机任务与脚本

```bash
# 1 停止 + 取消开机自启
sudo systemctl disable --now cmp40-gen2-retrain.service

# 2 删除单元文件
sudo rm -f /etc/systemd/system/cmp40-gen2-retrain.service

# 3 让 systemd 忘掉它
sudo systemctl daemon-reload
sudo systemctl reset-failed 2>/dev/null || true

# 4 删除脚本
sudo rm -f /usr/local/sbin/cmp40-gen2-retrain.sh
```

为什么必须"先 `disable` 再 `rm`"：只删单元文件不 disable，`/etc/systemd/system/multi-user.target.wants/` 里的软链接还留着，开机会报 `Failed to load ... No such file or directory`，看着像没卸干净。

### 9.3 第三步 · 验证清干净（四条都要"空"）

```bash
systemctl status cmp40-gen2-retrain.service 2>&1 | head -3        # Unit ... could not be found
systemctl is-enabled cmp40-gen2-retrain.service 2>&1              # not-found
ls -l /usr/local/sbin/cmp40-gen2-retrain.sh 2>&1                  # No such file or directory
ls /etc/systemd/system/ /etc/systemd/system/multi-user.target.wants/ 2>/dev/null | grep -i cmp40   # 无输出
```

四条全满足才算真干净。任何一条还有残留，就回 9.2 对应步骤重来。

### 9.4 第四步 · 重启生效并复查

```bash
sudo reboot
```

重启后：

```bash
nvidia-smi
GPU=$(lspci -D -d 10de:1f0b | awk '{print $1}')
lspci -vvv -s "$GPU" | grep -E 'LnkSta:|LnkCtl2:'
journalctl -b --no-pager | grep -i cmp40        # 应无输出
```

## 九个必须记住的坑

1. **`RETRAIN_FAIL status=1101` 是正常现象**，不要为它做任何激进操作。它是"太早"，不是"不支持"。
2. **`reboot` ≠ 冷启动**。装补丁、换驱动、以及要拿冷启动作最终结论时，必须 `poweroff` + 拔电 10 秒——解锁是易失的，热复位留下的状态会让结论不可信。**纯脚本/单元改动不受此限**，`reboot` 就能生效。
3. **仓库里的 `cmp40hx-driver-reprobe-gen2.sh` 只做 unbind/bind**，一个 `setpci` 都不发，跑完仍显示 `1101` 是它的正常行为，不能当故障证据。装了本手册的服务后不用再跑它。
4. **脚本必须装在 `/usr/local/sbin/`**。放在仓库 `tools/` 下，服务会报找不到文件。
5. **不要用 Link Disable / Secondary Bus Reset / `cmp40hx-alder-lake-link-disable-test.sh`**。能训到 Gen2，但会掉 GSP/RM；无显示输出的宿主上等于卡失联，只能断电救。
6. **`setpci` 回读变成 `0000` 不是写失败**，是硬件当前不认可该值（能力位还没就绪）。看到这个不要怀疑补丁。
7. **驱动版本必须匹配**。615 的补丁打到 610 上装不上；装错版本重装最费时间。
8. **源码树不要复用**。重装时删掉旧的 `open-gpu-kernel-modules-615.78.08/` 目录，避免旧补丁残留。
9. **Debian `/bin/sh` 是 dash**。任何带 `set -o pipefail` 的脚本都要用 `bash` 跑。

## 三段命令版（熟练后直接抄，段之间要重启）

中间夹着冷断电，**不可能一次贴完**。按下面三段分开执行：每一段结束都在自己的机器状态上跑完，再关机。

```
页 1  安装补丁 ──► sudo poweroff + 拔电 10 秒
页 2  装补训练脚本 + systemd 单元 ──► 再次 poweroff + 拔电 10 秒
页 3  验收：journal + lspci
```

> **页 2 结尾用 `reboot` 还是 `poweroff`？取决于你要验证什么：**
> - **只想让脚本和单元生效** → `sudo reboot` 就够。`enable --now` 当下已经把它跑了一次，systemd 重启后自然会再拉起。
> - **要把"开机自动生效"当最终验收** → 建议 `sudo poweroff` + 拔电 10 秒。理由不是"脚本需要冷启动"，而是**排掉上一次开机残留的 GPU 状态**（GSP/RM 是否收干净、PCIe 配置空间是否回到初值）。这样一旦 FAIL，能确定是脚本的问题，而不是脏状态导致的。
> - 折中做法：先 `reboot` 验一次，FAIL 再冷启动复核；两次结论一致才定性。
>
> 注意区分：页 1 结尾的冷断电是**必须**的（补丁要重新走 SEC2/FWSEC 初始化）；页 2 这里只是脚本，不是必须。

### 页 2 · 开机后装「延迟补训练」，然后再关机

开机进系统后直接贴这一段（不用先查 Gen2，正常情况这会儿就是 Gen1）。

```bash
# 1 写入补训练脚本到 /usr/local/sbin/
sudo tee /usr/local/sbin/cmp40-gen2-retrain.sh >/dev/null <<'CMP40_SCRIPT_EOF'
#!/usr/bin/env bash
# CMP 40HX late PCIe Gen2 retrain.
#
# Why this exists: the in-driver retrain runs inside nv_open(), immediately after
# the GSP bootstrap, and polls for 2 s. On at least one Intel server platform
# (D1581 / IIO root port 00:03.0) the link refuses to renegotiate at that moment
# even though the endpoint already advertises CAP2=00000006 and LnkCtl2=0002 --
# the driver logs "RETRAIN_FAIL status=1101". The same retrain issued a few
# seconds/minutes later trains to Gen2 x16 on the first try.
#
# So: wait for the driver, latch the endpoint capability with one rebind if it is
# still missing, then retry the standard sequence (TLS=5GT/s on both ends, Retrain
# Link on the upstream port) with a backoff schedule, and log which attempt won.
#
# Volatile by nature: run it on every boot.
set -u

TAG=cmp40-gen2
log() { printf '%s [%s] %s\n' "$(date '+%F %T')" "$TAG" "$*"; }

DEV=${CMP40_GPU:-$(lspci -Dnn -d 10de:1f0b 2>/dev/null | awk 'NR==1{print $1}')}
[ -n "${DEV:-}" ] || { log "no CMP 40HX (10de:1f0b) found"; exit 1; }

UP=$(basename "$(readlink -f "/sys/bus/pci/devices/$DEV/.." 2>/dev/null)")
[[ ${UP:-} =~ ^[0-9a-f]{4}:[0-9a-f]{2}:[0-9a-f]{2}\.[0-7]$ ]] || UP=""

rd32() { setpci -s "$1" "CAP_EXP+$2.L" 2>/dev/null | awk 'NR==1{print $1}'; }
rd16() { setpci -s "$1" "CAP_EXP+$2.W" 2>/dev/null | awk 'NR==1{print $1}'; }
wr16() { setpci -s "$1" "CAP_EXP+$2.W=$3" >/dev/null 2>&1; }

spd() { printf '%d' $(( 16#$1 & 0x0f )); }
wdh() { printf '%d' $(( (16#$1 >> 4) & 0x3f )); }

state() {
    printf 'CAP2=%s CTL2=%s LNKSTA=%s' \
        "$(rd32 "$DEV" 2c)" "$(rd16 "$DEV" 30)" "$(rd16 "$DEV" 12)"
}

has_gen2() {
    local c; c=$(rd32 "$DEV" 2c)
    [ -n "${c:-}" ] && [ $(( 16#$c & 0x04 )) -ne 0 ]
}

rebind() {
    log "rebind $DEV to latch the endpoint Gen2 capability"
    echo "$DEV" > /sys/bus/pci/drivers/nvidia/unbind 2>/dev/null \
        || { log "unbind rejected"; return 1; }
    sleep 1
    echo "$DEV" > /sys/bus/pci/drivers/nvidia/bind 2>/dev/null \
        || { log "bind rejected"; return 1; }
    nvidia-smi >/dev/null 2>&1
    return 0
}

attempt() {
    local c st i
    c=$(rd16 "$DEV" 30)
    [ -n "${c:-}" ] && wr16 "$DEV" 30 "$(printf '%04x' $(( (16#$c & ~0xf) | 0x2 )))"
    if [ -n "$UP" ]; then
        c=$(rd16 "$UP" 30)
        [ -n "${c:-}" ] && wr16 "$UP" 30 "$(printf '%04x' $(( (16#$c & ~0xf) | 0x2 )))"
        c=$(rd16 "$UP" 10)
        [ -n "${c:-}" ] && wr16 "$UP" 10 "$(printf '%04x' $(( 16#$c | 0x20 )))"
    fi
    for i in $(seq 1 40); do
        st=$(rd16 "$DEV" 12)
        if [ -n "${st:-}" ] && [ "$(spd "$st")" -ge 2 ]; then return 0; fi
        sleep 0.25
    done
    return 1
}

# Wait for the driver to attach and the device node to work.
i=0
while [ $i -lt 90 ]; do
    [ -e "/sys/bus/pci/devices/$DEV/driver" ] && nvidia-smi >/dev/null 2>&1 && break
    sleep 2
    i=$((i + 1))
done
log "start: $(state)"

if ! has_gen2; then
    rebind || log "rebind failed; will still try the retrain"
fi
if ! has_gen2; then
    log "Gen2 capability still absent after rebind; nothing to retrain"
    exit 1
fi

# Cumulative backoff: 0 / 5 / 20 / 55 / 130 / 265 s after the driver settled.
# The journal tells you which attempt won, i.e. how long this board needs.
for delay in 0 5 15 35 75 135; do
    sleep "$delay"
    if attempt; then
        log "PASS at +${delay}s: $(state) speed=$(spd "$(rd16 "$DEV" 12)") width=x$(wdh "$(rd16 "$DEV" 12)")"
        exit 0
    fi
    log "attempt at +${delay}s still Gen1: $(state)"
done

log "FAILED: link stayed at 2.5GT/s"
exit 1
CMP40_SCRIPT_EOF

sudo chmod 0755 /usr/local/sbin/cmp40-gen2-retrain.sh

# 2 写入 systemd 单元
sudo tee /etc/systemd/system/cmp40-gen2-retrain.service >/dev/null <<'CMP40_UNIT_EOF'
[Unit]
Description=CMP 40HX late PCIe Gen2 retrain
Documentation=https://github.com/Cyridd/cmpunlocker
After=systemd-modules-load.service nvidia-persistenced.service
# 不要加 ConditionPathExists=/dev/nvidia0：该条件只在启动瞬间判一次，
# 那时驱动还没建出节点就会被跳过，且 oneshot 不会重试。
# 等待驱动的工作交给脚本自己的 180 秒轮询。

[Service]
Type=oneshot
ExecStart=/usr/local/sbin/cmp40-gen2-retrain.sh
RemainAfterExit=yes
TimeoutStartSec=600

[Install]
WantedBy=multi-user.target
CMP40_UNIT_EOF

# 3 启用并当场跑一次（这一步只是确认脚本能跑通，不是最终验收）
sudo systemctl daemon-reload
sudo systemctl enable --now cmp40-gen2-retrain.service
journalctl -u cmp40-gen2-retrain -n 20 --no-pager

# 4 重启（二选一）
#    只验脚本生效：sudo reboot
#    做最终验收：  sudo poweroff   （等灯灭 → 拔电 10 秒 → 上电）
sudo poweroff
```

### 页 3 · 冷启动后验收

开机 2–3 分钟后执行。

```bash
# 1 服务状态与本次开机的完整日志
systemctl status cmp40-gen2-retrain --no-pager
journalctl -u cmp40-gen2-retrain -b --no-pager

# 2 链路实际状态（通过标准：Speed 5GT/s, Width x16）
lspci -vvv -s $(lspci -Dnn -d 10de:1f0b | awk 'NR==1{print $1}') | grep -E 'LnkSta:|LnkCtl2:'

# 3 四项能力确认
nvidia-smi                                   # 算力：驱动正常、显存 8192MiB
nvidia-smi -q | grep -A2 'BAR1 Memory'       # ReBAR：Total 8192 MiB
```

**通过标准：**

```text
[cmp40-gen2] PASS at +Ns: ... speed=2 width=x16
LnkSta:  Speed 5GT/s, Width x16
LnkCtl2: Target Link Speed: 5GT/s
```

记下 `PASS at +Ns` 里的 `N`——那是这台机器的确切等待时间。稳定后可以把脚本里 `for delay in 0 5 15 35 75 135` 改成固定 `sleep N`，开机到 Gen2 会更快。

三段跑完约 10–15 分钟、两次冷启动。三段都过不了再进步骤 8 的分流表；要理解"为什么这样就能修好"、看完整寄存器日志和定位过程，翻 `CMP40HX-项目总结与Gen2排查实录.md`。
